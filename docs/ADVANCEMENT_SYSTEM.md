# Tales of Two — Hero Advancement System

## Purpose
Hero advancement uses one shared attribute economy from character creation through long-term play. The Story Director never awards arbitrary stat or skill increases. Level math is server-owned; allocation is player-owned.

## Character Creation
- Starting stat budget: 8 points.
- Starting skill budget: 6 points.
- Creation stat cap: 3.
- Creation skill cap: 2.
- All starting points must be allocated during creation.

## Level-Up Advancement Awards
When a Hero gains levels during a journey:
- Every level gained earns **1 Skill Point**.
- Reaching each even-numbered level earns **1 Stat Point**.

Examples:
- Level 1 → 2: +1 Skill Point, +1 Stat Point.
- Level 2 → 3: +1 Skill Point.
- Level 3 → 4: +1 Skill Point, +1 Stat Point.
- Level 3 → 6: +3 Skill Points, +2 Stat Points.

## When Points Become Spendable
Level-up allocation points are tracked during an adventure but are not banked onto the permanent Hero until the adventure is completed.

At successful adventure completion, earned points are transferred to the Hero's unspent advancement pool and appear in the finale's **HERO ASCENDANCY** panel.

This boundary is intentional. It prepares the system for provisional journey progression and abandon/rollback rules.

## Advancement Caps
Post-creation caps are intentionally higher but bounded because checks use d20 + stat + skill + modifiers.

- Advancement stat cap: 6.
- Advancement skill cap: 5.

These caps prevent high-level Heroes from trivializing the check engine while still allowing meaningful specialization.

## Allocation
The finale allows the player to spend banked points one at a time:
- `RAISE STAT` consumes 1 unspent Stat Point.
- `RAISE SKILL` consumes 1 unspent Skill Point.

Unspent points remain on the Hero and can be allocated later.

Fallen Heroes cannot spend advancement points unless a future resurrection system explicitly changes that rule.

## Authority
- Level calculation: server-owned.
- Advancement-point awards: server-owned.
- Caps and validation: server-owned.
- Allocation target: player-selected.
- Director/AI: no authority over advancement math.
