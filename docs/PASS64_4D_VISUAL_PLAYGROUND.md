# Pass 64.4D — Background and Top Menu Playground

## Strict scope

**No page content. No Hero cards. No sidebar tabs. No changes to `/game`.**

This package adds a protected, isolated React playground route at:

`/game/visual-playground`

The page contains **only** a full-viewport photographically composed tabletop with an open *blank* ivory book, and an accessible real-DOM header with a compass, Tales of Two wordmark, parchment navigation ribbon and signed-in profile menu.

The six top menu entries are local visual-preview selections (they only change the active menu item); the wordmark and profile menu provide exits to real pages. All lettering is HTML, not printed into the background. The image has a readable `alt` description. On narrow screens, the top navigation collapses into a menu.

This is a staging-only visual development surface. The game homepage, Reader, gameplay systems, book content and business data are intentionally untouched.

## Install

Place the ZIP in `OnlineAdventureGame/assets/AWS/` and from `root/` run:

```bash
bash scripts/install-overlay.sh ../assets/AWS/tales-of-two-pass64-4d-visual-playground.zip && ./scripts/check-project.sh
```

Only after the full checks succeed, deploy staging with:

```bash
./scripts/release-staging.sh "Pass 64.4D: isolated blank-book visual playground and parchment top menu"
```

Visit `https://onlinetextadventure.com/game/visual-playground` after staging deploy.

## Visual review acceptance criteria

- Desktop: book and tabletop occupy viewport, no document scrolling.
- Completely blank ivory pages, with no cards or in-book content.
- Exactly one visual top menu, generated by React, never duplicated in the background photo.
- No separate left-side page tabs in this playground.
- All six menu items show clear focus/active states.
- Desktop 1280/1440/1600 and mobile 390 must not horizontally overflow.
- The URL `/game` remains unchanged.
- Asset is bundled locally; there is no WebGL, font download, or external tracking.

**Limitations**: The art direction is a first photographic base. We have not replaced the production Home design, proved the complete application build, or implemented page transitions or theme swaps here.
